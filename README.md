# Aurora X A4 Flyer

## 概要
Aurora XブランドのA4両面チラシ制作プロジェクト。

## 制作物
- A4両面チラシ
- 表面：ブランド訴求・第一印象重視
- 裏面：サービス概要・導入メリット・問い合わせ導線

## 目的
ITイベントや営業活動で配布し、Aurora Xブランドおよび関連プロダクトへの興味喚起を行う。

## 想定読者
- 企業の経営層
- 情シス担当者
- 営業部門
- カスタマーサポート部門
- 業務改善を検討している担当者

## ブランド方針
Aurora Xは、企業のコミュニケーション業務を進化させるブランド。
SMS、IVR、AI Callなどのプロダクト群を通じて、企業と顧客の接点をよりスマートにする。

## 注意点
- 情報を詰め込みすぎない
- A4紙面ではブランドの第一印象を重視する
- 詳細説明はWebやQRコードに誘導する
- Aurora IVRとAurora AI Callは別プロダクトとして扱う
