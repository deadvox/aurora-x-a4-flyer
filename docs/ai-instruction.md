# AI Instruction

このリポジトリは、Aurora XブランドのA4両面チラシ制作のための資料です。

AIは以下の前提を守って提案してください。

## 前提
- 制作物はA4両面チラシ
- BtoB向け
- ITイベントや営業配布で使用
- ブランド訴求が主目的
- 情報を詰め込みすぎない
- 詳細はWebサイトやQRコードへ誘導する

## 重視すること
- Aurora Xブランドの先進性
- 信頼感
- 読みやすさ
- 紙面上の余白
- 見出しと本文の階層
- 表面と裏面の役割分担

## 提案してほしいこと
- A4両面の構成案
- 表面と裏面の情報設計
- キャッチコピー案
- 見出し案
- テキスト量の調整案
- デザイン方向性
- レイアウト改善案

## 避けること
- 情報を詰め込みすぎる提案
- Webページのような長文構成
- チラシっぽすぎる安売り感
- Aurora IVRとAurora AI Callを混同すること
- プロダクト詳細を無理に全部説明しようとすること

## 回答スタイル
- デザイナーが判断しやすいように整理する
- 表面、裏面に分けて提案する
- 必要に応じて優先順位をつける
- 紙面に入れるべきもの、Webに逃がすべきものを分ける
