# Design Rule

## 基本方針
Aurora Xブランドの先進性、信頼感、清潔感を表現する。

## デザインキーワード
- 先進的
- 信頼感
- スマート
- 余白
- BtoB
- クリーン
- テクノロジー
- 未来感

## トーン
過度に派手にしない。
BtoB向けのため、信頼感を優先する。
ただし、無難で地味になりすぎないよう、グラデーションや光の表現で先進性を出す。

## レイアウト方針
- 情報を詰め込みすぎない
- 1面に入れる要素を絞る
- 余白を大きめに取る
- 見出し、本文、補足の階層を明確にする
- 紙面端ギリギリに要素を置かない
- ブロックごとの呼吸を大切にする

## 表面デザイン
- Aurora Xブランドのロゴを主役にする
- キャッチコピーを大きく扱う
- 背景は白〜淡いグラデーション、または深いネイビー系も検討可
- プロダクト詳細は載せすぎない
- 第一印象で「ちゃんとした企業向けサービス」に見えることを重視する

## 裏面デザイン
- サービス群の整理
- 課題、解決策、導入メリットの順で見せる
- テキストは短く
- 詳細はQRコードでWebへ誘導
- 問い合わせ導線を明確にする

## 避けたい表現
- 安っぽい未来感
- 過剰な装飾
- 情報の詰め込み
- 小さすぎる文字
- 意味のないアイコンの多用
- チラシ感が強すぎる販促デザイン
